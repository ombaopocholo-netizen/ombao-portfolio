# Personal Portfolio Website

A responsive dark-themed portfolio built with plain HTML, CSS and JavaScript (no frameworks).

## Project structure

```
portfolio/
├── index.html
├── style.css
├── script.js
├── images/
│   ├── profile.jpg
│   ├── project1.jpg
│   ├── project2.jpg
│   └── project3.jpg
└── README.md
```

## How to run

1. Open the `portfolio` folder in Visual Studio Code (File > Open Folder).
2. Right-click `index.html` and choose **Open with Live Server** (install the "Live Server" extension first), or just double-click `index.html` to open it in your browser.

## How to customize

- **Your photo:** replace `images/profile.jpg` (keep the same file name, square photo works best).
- **Project screenshots:** replace `images/project1.jpg`, `project2.jpg`, `project3.jpg`.
- **Text, email, phone, location:** edit them in `index.html` (search for `markpombao@example.com` and `+63 912 345 6789`).
- **Project links:** in `index.html`, change `href="#"` on each "View Project" button to your real URL.
- **Social links:** change the `href="#"` on the social icons (Contact section and footer).
- **Colors:** change the variables at the top of `style.css` (`--purple`, `--blue`, `--bg`, ...).
- **Typing animation words:** edit the `roles` list in `script.js`.
